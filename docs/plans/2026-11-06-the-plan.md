## 3 · Assets and licences (J22) - the rule set

1. **What ships**: only what its own grant, read and quoted at the source, lets us redistribute modified in an
   open-source download (CC0; CC BY with credit; MIT / Apache / BSD; custom grants that allow it). [user; AGENTS.md]
2. **Licences are labels, never filters** in research and imports (SHIP / FETCH / IMPORT / TRAIN / REFERENCE).
3. **Local tests may use anything**; nothing from them ships; CC5 / MetaHuman renders stay out of the repo.
4. **Clean-room**: no reference app's code, shaders, meshes, morphs or content ships; MetaHuman's *names* on our face
   rig are the one approved exception (item 10, TASKS L258-263) - AGENTS.md to say so (Q-AG).
5. **Imports** keep provenance and licence; projects reference, not embed, restricted content.
6. **Likeness**: a shipped character is never one scan's face - written into the spec, with a recognition test (TO
   BUILD); **NOT STANDARD** (the standard - model releases - our CC BY scans lack).
7. **Attribution in three layers**: an `ATTRIBUTION.md` row per source and per tool that builds shipped data (missing
   today: RealDenseFace, FLAME 2023 Open, SegFace, Anny; Fabienne & Percy cited but absent); REUSE labels with every
   licence text in `LICENSES/` and the manifest's SPDX list; credits shipped inside the extension (Q-LIC-2).
8. **Patents**: before building near a found patent, read the independent claims in full, design so the piece never
   holds every element of a claim, write the reading into RESEARCH ("not legal advice"). Read 2026-11-06 (RESEARCH §14):
   the shipped microrelief lacks Disney's claim 1's first element (a flat tile, not nodes sampled from a 3D face as
   pores); Disney's orientation-bin wrinkles are granted to 2044 (US 12,651,397) - that route is out; Microsoft's
   tension patent (US 12,062,140, to 2043) bars building wrinkle textures as tension-weighted combinations of expression
   maps - tension may only set the DNA's weights; Sony's meniscus plug-in (US 9,269,185 claim 16, to 2033) reads close to
   our tearline's automatic placement -> Q-EYE-4; the mixer holds none of US 8,922,553's per-region model solve.
10. **Where it is published**: extensions.blender.org takes only CC0 assets inside an extension (its Terms 1.2) - ours
   bundle CC BY, Apache, MIT and Ten24 data, so JustStage ships through its own installer and a self-hosted extension
   repository (the documented route), never the official platform. BY-SA content (Hair Styles demo, TAU) may ship
   inside the GPL extension only under CC's one-way BY-SA 4.0 -> GPLv3 rule ("must specify version 3"; Hair Styles names
   no version - unclear).
9. **No emails, no purchases** [user]: sources needing a custom licence stay IMPORT / REFERENCE.

Settled at the source today: HSRD-100 is CC BY 4.0 ("Commercial use allowed", "Distribution allowed"; RESEARCH §14);
Ten24's sample: "Feel free to use this scan as you wish for both commercial and personal projects ... credit wherever
it's used" (RESEARCH L2420's "non-commercial" is stale). Fixes, no decision needed: the library skins' licence labels
