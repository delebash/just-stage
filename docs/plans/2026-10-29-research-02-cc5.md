# Research 02 — Character Creator 5 (CC5) and its plugins: feature inventory, data model, API

Researched 2026-10-29 by a research agent (clean-room: public pages and docs only; nothing copied).
Labels on each fact: **page read** = the page itself was fetched and read; **search snippet only** =
seen only in a search-result summary; **TOC title** = only the topic title in the CC5 online manual's

## Top findings

1. **Latest version is CC 5.2, released 2026-10-29 (today)**: AI 3D Generator (Tripo / Hunyuan, cloud),
   CC Wrap / Body Wrap (turns any humanoid mesh into a rigged CC base), eight Cloth Types with Tuck-in
   conform, a rebuilt skin-weight editor, GLB import, Quad Remesher and high-to-low baking —
   [CC5.2 release note](https://discussions.reallusion.com/t/character-creator-5-2-release-note-ai-3d-generator-cc-wrap-enhanced-outfit-workflows-and-bug-fixes/18782) (2026-10-29, page read).
2. **CC5 launched 2025-08-27.** Over CC4 it added: the HD base (two extra subdivision levels, "up to 16
   times more mesh detail", 8K skin, displacement + cavity maps), HD morphs, reworked eyes/lashes, two new
   facial profiles (Extended Plus, HD), ActorMIXER, and a MetaHuman-shared skeleton and face controls —
   [CG Channel](https://www.cgchannel.com/2025/08/reallusion-releases-character-creator-5/) (2025-08-28, page read).
3. **Windows only.** Windows 10/11 64-bit; min 7th-gen i5, 16 GB RAM, 8 GB VRAM (GTX 10 / RX 5500 XT),
   30 GB install + 200 GB DDS cache; recommended 64 GB RAM. No macOS or Linux build —
   [download page](https://www.reallusion.com/character-creator/download.html) (undated, page read);
   [manual: System Requirements](https://manual.reallusion.com/Character-Creator-5/Content/ENU/5.0/04-Introducing-the-User-Interface/System-Requirements.htm) (build 2026-10-29, page read).
4. **One topology family underlies everything**: CC3 Base+ topology at SubD 0/1/2 (each level with its own
   normal and displacement maps), downgradable to ActorBUILD / LOD1 / LOD2 with bone templates of
   **101 / 54 / 22** bones —
   [manual: Character Level Table](https://manual.reallusion.com/Character-Creator-5/Content/ENU/5.0/09-Character-Level/Character-Level-Table-and-Distance.htm) (page read);
   [HD character base page](https://www.reallusion.com/character-creator/hd-character-base.html) (undated, page read).
5. **Facial rig is tiered by profile**: Standard 75 sliders, Extended 160, Extended Plus 160 + 26
   non-linear, HD 262 expression + 128 corrective (= 390); 15 visemes (8 lip + 7 tongue phoneme pairs) —
   [manual: Slider Tables](https://manual.reallusion.com/Character-Creator-5/Content/ENU/5.0/05-HD-Character/Slider-Table-for-Facial-Profiles.htm),
   [manual: HD Facial Profile](https://manual.reallusion.com/Character-Creator-5/Content/ENU/5.0/05-HD-Character/HD-Facial-Profile-Intro.htm) (build 2026-10-29, page read).
6. **CC and iClone share one Python API (RLPy)**: SWIG-wrapped, PySide2 / Qt 5.15, plugins dropped in
   `Bin64\OpenPlugin`, menus under Plugins. The official docs cover the iClone 8.0 API only; the
   full list is the `RLPy.py` file in the install —
   [forum, staff reply](https://discussions.reallusion.com/t/is-there-a-way-to-add-collections-tags-to-assests-via-python/16615) (2026-02-24, page read);
   [IC8 Python API wiki](https://wiki.reallusion.com/IC8_Python_API) (2023-04-10, page read).
7. **No outside-facing API.** A third party built an HTTP + MCP bridge (an LLM drives CC5 through a
   Python plugin on a Qt timer) because CC5 has none —
   [cc5-mcp-server README](https://github.com/MorphoCore-Pty-Ltd/cc5-mcp-server) (pushed 2026-09-05, page read).
8. **Paid add-ons around a $299 core**: ActorMIXER PRO $199, HD Ultimate Morphs $149, CC5 Deluxe
   $499 (launch), Headshot 3 $199. Subscriptions start at $29/month or $99/year —
   [CG Channel 2025-08](https://www.cgchannel.com/2025/08/reallusion-releases-character-creator-5/);
   [CG Channel 2026-07](https://www.cgchannel.com/2026/07/reallusion-releases-headshot-3-0/) (page read).
9. **The pipeline is free plugins, one per target**: Auto Setup for Unreal (now an "All-in-One" with
   Control Rig and Live Link, UE 5.8+), Unity, Blender, Maya, 3ds Max and Marmoset; GoZ for ZBrush; USD to
   Omniverse —
   [pipeline page](https://www.reallusion.com/character-creator/pipeline.html);
   [Auto Setup for Unreal](https://www.reallusion.com/auto-setup/unreal-engine/default.html) (undated, page read).
10. **AI features run on a cloud credit system ("AI points" / "DA points")**: Tripo and Hunyuan for meshes,
    Google "Nano Banana" for Headshot reference images (a 4K image costs 30 DA points, about $0.30), and
    third-party video models in AI Studio. FashionGen instead runs a bundled local ComfyUI —
    [CG Channel Headshot 3](https://www.cgchannel.com/2026/07/reallusion-releases-headshot-3-0/) (2026-07-07, page read);
    [5.2 Grand Update post](https://discussions.reallusion.com/t/character-creator-5-2-grand-update-from-ai-generated-meshes-to-living-3d-characters/18783) (2026-10-29, page read).
11. **Clothing is fit-and-layer, not design**: conform, eight cloth types, tuck-in and shrink-wrap,
    auto-hide of the body under clothes, skin-weight transfer, PhysX soft cloth. Garment design happens
    outside CC (Marvelous Designer, MetaTailor, or AI generation) —
    [custom outfit page](https://www.reallusion.com/character-creator/custom-outfit.html) (undated, page read).
12. **Sculpting inside CC is light**: Edit Mesh brushes and Body Wrap refine brushes. Deep sculpting goes
    to ZBrush through GoZ, and expression sculpting through the paid ZBrush Face Tools —
    [CC5 manual TOC]; [ZBrush page](https://www.reallusion.com/character-creator/zbrush.html) (undated, page read).
13. **Rendering is a real-time viewport only** (TAA, voxel GI, IBL, IES, shadow maps, tessellation; DLSS
    fixes in 5.2). The only path tracer is the separate Iray plugin, and whether CC5 supports it is
    conflicting —
    [manual: Real-time Render Options](https://manual.reallusion.com/Character-Creator-5/Content/ENU/5.0/04-Introducing-the-User-Interface/Real-Time-Render-Options-Section.htm) (page read);
    [pre-launch forum thread](https://discussions.reallusion.com/t/i-just-saw-an-add-for-character-creator-5/13772?page=3) (2025-04-14, page read).
14. **Top user complaints**: launch bugs and regressions (seven bug-fix point releases), content and
    add-ons the tutorials don't mention you must buy, subscriptions that can't be refunded, no
    joint-corrective (JCM) system, and native features (JCMs) lost on FBX export —
    [issues thread](https://discussions.reallusion.com/t/official-character-creator-5-issues-thread/15102) (2025-08-28/29);
    [buyer's-remorse thread](https://discussions.reallusion.com/t/worse-purchase-ever-made-instant-buyers-remorse/16682) (2026-03-03);
    [pre-launch thread](https://discussions.reallusion.com/t/i-just-saw-an-add-for-character-creator-5/13772?page=3) (2025-04-15) (all page read).
15. **Most praised**: HD skin and mesh quality, the number of facial blendshapes, ActorMIXER blending,
    and an Unreal pipeline that needs no retargeting —
    [issues thread](https://discussions.reallusion.com/t/official-character-creator-5-issues-thread/15102) (page read); review snippets (search snippet only, see §9).

### What CC5 added over CC4
All from [CG Channel 2025-08-28](https://www.cgchannel.com/2025/08/reallusion-releases-character-creator-5/) (page read) unless noted:
- HD character base with **two more subdivision levels**, "up to 16 times more mesh detail".
- New HD morph system. The extra HD morphs come in the paid **HD Ultimate Morphs** pack: 20 head and
  152 body morphs.
- Reworked eyes: pupil depth, tearline, eye ducts and more detailed iris textures.
- Multi-layer eyelashes that use the Smart Hair Shader.
- Textures up to **8K**.
- Pores and wrinkles as **displacement** maps as well as normal maps.
- Two new facial profiles, **Extended Plus** and **HD**. HD is compatible with MetaHuman's facial
  expression system.
- **ActorMIXER**: non-destructive blending of up to **six** existing characters, as a whole body, head
  or single facial feature. The base version is included; ActorMIXER PRO is paid.
- UE4 and UE5 skeleton export with MetaHuman / UEFN bind poses, and import of MetaHuman Animator
  facial data as CSV.
- New free Auto Setup plugins for **Maya** (2024/2025, Arnold 5.4.3+, Windows only) and **Marmoset Toolbag**
  (5.0+, Windows only).
- CC4 content and plugins work in CC5; iClone was updated (8.6) for CC5 features.
- A new **Constraint System** keeps expressions in anatomically plausible ranges. **Non-linear facial
  animation** uses "curve-based motions and mesh elasticity". CC3+ characters can be upgraded to the HD
  facial profile — [CG Channel unveil](https://www.cgchannel.com/2025/07/reallusion-unveils-character-creator-5/) (2025-07-21, page read).
- The product page's CC4-vs-CC5 table marks these as likely CC5-only: the Extended-Plus and HD facial
  profiles, MetaHuman compatibility, MHA facial import, Daz Transformer to HD, HD morphs, eyelash
  elements, subdivision normal baking and AI render —
  [CC product page](https://www.reallusion.com/character-creator/) (undated, page read; bold "new"
  markers were lost in the fetch, so the column assignment is approximate).
- CC4 owners got free upgrades for Headshot 2, SkinGen Premium and ZBrush Face Tools. **Headshot 1 and
  the Iray plugin are not supported in CC5** (staff, before launch) —
  [forum](https://discussions.reallusion.com/t/i-just-saw-an-add-for-character-creator-5/13772?page=3) (2025-04-14, page read).
  This conflicts with the CC5 manual's Plugins menu, which still lists "Iray Render" (§2, plugins).

## 5 · Character data model

### Base mesh family and topology
- Generations: CC1, CC3, CC3 Base+, CC5 HD, Game Base, iC Standard (G3/G4/G6), Humanoid (actorBUILD,

- Published counts. Sources disagree because they count different scopes:

    for nails and eyelashes — [character spec](https://www.reallusion.com/content/characterspec/) (undated, page read).
  - CC3+ "Optimized quad for subdivision sculpting (13,580 face)"; scope (whole body or head) not

  - Level table, unit "K": CC Standard **80**, actorBUILD **60**, Humanoid LOD1 **20**, LOD2 **7**,
    Bone **0.8**; camera distances 0 / 2.8 / 10 / 20.8 / 42 m —
    [M: Level Table](https://manual.reallusion.com/Character-Creator-5/Content/ENU/5.0/09-Character-Level/Character-Level-Table-and-Distance.htm) (page read).
  - The LOD page gives "CC Avatar (CC3+) **240k+** (including cloth and hair)", actorBUILD 60k+,
    LOD1 20k, LOD2 7k, 0.8k — [LOD page](https://www.reallusion.com/character-creator/lod-characters.html) (page read).
- CC3+ topology has quad faces with "ideal edge-loops", joint rings and muscle lines for sculpting and
  scans; tear-line and occlusion meshes fit the eyelids; there are 12 base characters —
  [M: Topology](https://manual.reallusion.com/Character-Creator-5/Content/ENU/5.0/05-Character/Topology-Mesh-Enhancements.htm) (page read).
- Assessment: two Catmull-Clark levels multiply faces by 16, which matches "16×". The CC3+ body
  (~14–17K quads) would be ~220–270K quads at SubD 2. This is my arithmetic, not a published figure.

### Skeleton
- Bone templates are **101** (CC3+ standard), **54** (actorBUILD) and **22** (LOD). Removable groups:
  twist / share bones (up to 22), fingers (up to 30), feet / toes, facial, breast / neck —
  [LOD page](https://www.reallusion.com/character-creator/lod-characters.html) (page read).
- **Bone naming**: CC3+ bones use the `CC_Base_` prefix, e.g. `CC_Base_BoneRoot`, `CC_Base_Hip`,
  `CC_Base_JawRoot`, `CC_Base_FacialBone`, `CC_Base_L_CalfTwist01/02`, `CC_Base_L_Breast`. Reallusion's
  Blender add-on maps them to UE names (`pelvis`, `spine_01`, `thigh_l`, `clavicle_l`, `neck_01`,
  `head`) — [cc_blender_tools rigify_mapping_data.py](https://github.com/reallusion/cc_blender_tools) (GPL-3.0, pushed 2026-09-11, file read for names only).
- Export can rename to the **Epic UE4 or UE5 skeleton**, with UE hand / foot IK and a T-pose bind pose —
  [M: FBX Character](https://manual.reallusion.com/Character-Creator-5/Content/ENU/5.0/17-Export/FBX-Advanced-Settings-Character.htm) (page read).
- The UE plugin's skeletons add spine and hand bones and have bind-pose presets for retargeting —
  [Auto Setup UE](https://www.reallusion.com/auto-setup/unreal-engine/default.html) (page read).
- CC5 characters "use the same skeleton structure as MetaHuman" —
  [M: MetaHuman Interop](https://manual.reallusion.com/Character-Creator-5/Content/ENU/5.0/17-Metahuman-Interoperability/MetaHuman-Interoperability.htm) (page read).
- Users report CC5's Spine05 sits in the sternum, not between the clavicles, which breaks physics —
  [issues thread](https://discussions.reallusion.com/t/official-character-creator-5-issues-thread/15102) (2025-08-28, page read).

### Facial bones vs blendshapes
- Facial expressions can be **bone-driven (skinned) or morph-driven**. FBX export can convert skinned
  expressions to morphs, and fold mouth-open into one morph that also drives teeth and tongue —
  [M: FBX Character](https://manual.reallusion.com/Character-Creator-5/Content/ENU/5.0/17-Export/FBX-Advanced-Settings-Character.htm) (page read).
- Removing facial bones on LOD also removes the matching blendshapes —
  [LOD page](https://www.reallusion.com/character-creator/lod-characters.html) (page read).
- The jaw, eyes and teeth have bones (jaw-bone scale is mentioned in a 5.13 fix) —
  [5.13 post](https://discussions.reallusion.com/t/character-creator-5-13-is-now-released-independent-ai-studio-workflow-enhancements-and-bug-fixes/18378) (page read);
  `CC_Base_JawRoot` in the Blender add-on (above).

## 6 · Python API (input for JustStage's API design)

- **One API for CC and iClone.** "CC and IC share the same Python API"; the full list for a version is
  `…\Character Creator 5\Bin64\RLPy.py`; the wiki documents the IC 8.0 API, and later additions "may
  not be documented" —
  [forum, Johnny_RL](https://discussions.reallusion.com/t/is-there-a-way-to-add-collections-tags-to-assests-via-python/16615) (2026-02-24, page read).
- **Entry points**: Script › **Load Python** (.py) and Script › **Console Log** —
  [M: Script menu](https://manual.reallusion.com/Character-Creator-5/Content/ENU/5.0/03-Main-Menu/Menu-Script.htm) (page read).
  Installed plugins live in `Bin64\OpenPlugin\<name>\main.py` and appear under the **Plugins** menu —
  [CCiC Blender plugin README](https://github.com/reallusion/CCiC-Blender-Pipeline-Plugin) (page read);
  [reallusion/iClone README](https://github.com/reallusion/iClone) (page read).
- **Runtime**: Python **3.8**, Qt **5.15.2** with **PySide2** ("the script must initialize PySide2") per
  the IC8 docs — [IC8 Python API](https://wiki.reallusion.com/IC8_Python_API) (2023-04-10, page read).
  A third-party CC5 developer note (2026-09) says PySide2 is required, PySide6 doesn't work, and code
  needs `from __future__ import annotations` for type hints (which implies Python below 3.10) —
  [cc5-mcp-server `.claude/rules/cc5-dev.md`](https://github.com/MorphoCore-Pty-Ltd/cc5-mcp-server) (page read).
  The exact Python version in CC5 was not confirmed.
- **Size**: the wrapper is SWIG-generated, with "206 classes | 1188 constants | 287 functions" per a
  third-party extraction from CC5's RLPy.py. The same repo's notes say "163 classes" — inconsistent —
  [cc5-mcp-server docs](https://github.com/MorphoCore-Pty-Ltd/cc5-mcp-server) (page read).
- **Groups** (IC8 docs) — [IC8 Python API](https://wiki.reallusion.com/IC8_Python_API) (page read):
  - Mathematics: vectors, matrices, quaternions, transforms, colour
  - System: RStatus, RTime, RVariant, RFileIO, RGlobal, RPyTimer, RApplication
  - Scene: RIObject, RINode, RIProp, RIAvatar, RICamera, lights, particles, RScene, material component
  - Animation: keys and controls, clips, skeleton, viseme, morph, HIK effector and face components
  - MotionCapture: body, hand and facial devices, mocap manager
  - Events, UI (RIDialog, RIDockWidget, RUi), Media (audio), Networking (RTcpClient, RUdpClient)
- **CC-specific surface** (third-party extraction of CC5 RLPy.py, page read):
  - `RIAvatar`:
    - components: skeleton, viseme, shaping (morphs), morph, material, physics, HIK effector, face,
      facial profile
    - generation and type
    - lists of accessories, clothes, hair; `LoadAccessoryWithTransferSkinWeight`
    - `ConvertTo` and `DoCharacterization`
    - `ReplaceMesh` (with auto-rig)
    - SubD level get / max / switch
    - morpher constraints and `UpdateWrinkle`
  - `RIAvatarShapingComponent`: morph categories, IDs, names, min/max, get/set weight, `CreateSlider`.
  - `RIAccessory`: `TransferSkinWeight`, `ConvertToHair`, `ConvertToFaceHair`.
  - `RHeadshot`: `CreateHeadFromPhoto`, `ImportHeadFromObj`.
  - Also: export settings for FBX / GLB / USD / GoZ, `RIOmniConnectorManager`,
    `RIMotionDirectorManager`, and building / floor / wall generator objects (iClone).
- **Events** (`REventCallback`, CC5):
  - files: before load, loaded, after load, before save, saved
  - selection changed, object data changed / added / deleted, hierarchy changed
  - undo/redo done, played / stopped, current time changed, timer / scene updated, dialog mode changed
  - `OnAPInitialized`, `OnSmartGalleryInitialized`, `OnOmniLiveChanged`, image async load
  - Source: same extraction (page read). Earlier docs describe the callback model —
    [RLPy release notes](https://wiki.reallusion.com/IC_Python_API:RLPy_Release_Notes) (2020-02-20, page read).
- **UI hooks** (`RUi`) — [RUi wiki](https://wiki.reallusion.com/IC_Python_API:RLPy_RUi) (2020-05-12, page read):
  - `GetMainWindow` (the QWidget to parent PySide UI)
  - `AddMenu` / `RemoveMenu` under the Plugins menu
  - `AddHotKey` / `RemoveHotKey`
  - message box, file open / save dialogs
  - `CreateRDialog`, `CreateRDockWidget`
  - CSS type and resolution queries
  - no viewport-drawing hooks documented
- **Limits**:
  - No tags or collections API — staff, 2026-02 (above).
  - Loading `.cchair` through `LoadAccessoryWithTransferSkinWeight` crashed CC5 5.11; status "Released
    in 5.13" — [FeedbackTracker 12650](https://www.reallusion.com/FeedBackTracker/Issue/Bug-Report-Hair-ccHair-cannot-be-applied-to-an-avatar-via-the-RLPy-API-generated-by-Claude) (2026-07-15, page read).
  - Third-party CC5 notes ([cc5-mcp-server](https://github.com/MorphoCore-Pty-Ltd/cc5-mcp-server), page read):
    - not thread-safe (call from the main thread via QTimer)
    - bad arguments can segfault the C++ host
    - edits must be wrapped in `BeginAction` / `EndAction` (undo)
    - `ObjectModified` must be called for the viewport to refresh
    - plugins declare `rl_plugin_info = {"ap": "iClone", "ap_version": "8.0"}` with
      `initialize_plugin` / `uninitialize_plugin`
  - The docs are stale (wiki pages 2020–2023), and there is no published CC5 API changelog — above sources.
  - Users asked for a CC Python API for years; a 2024 tracker request was still "Active" —
    [FeedbackTracker "CC Python API"](https://reallusion.com/FeedBackTracker/Issue/CC-Python-API) (search snippet only).
- **No external API.** Outside apps reach CC only through an in-process plugin that opens its own
  socket. Examples: Reallusion's Blender "DataLink"
  ([CCiC plugin](https://github.com/reallusion/CCiC-Blender-Pipeline-Plugin), page read) and the
  MCP bridge on HTTP port 5101 ([cc5-mcp-server](https://github.com/MorphoCore-Pty-Ltd/cc5-mcp-server), page read).
- **Distribution**: Python plugins can be sold on the Reallusion Marketplace as zips, one per host
  version, with optional trials —
  [wiki](https://wiki.reallusion.com/IC_Python_API:Uploading_and_Managing_Marketplace_Plugins) (2023-04-10, page read).
- Assessment, for JustStage's API:
  - CC's API is an in-process scripting binding, added after the app was built, with no
    command/undo model exposed beyond BeginAction / EndAction.
  - Its traits are a thread-affinity rule, segfault-on-bad-args, and lagging docs.
  - The lessons: one command layer that UI, scripts and remote clients all use; undo on that
    layer; and versioned, generated docs.
