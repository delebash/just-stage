# The CC5-style window — the working doc (read this FIRST after any compaction)

> Epic's page). TASKS: "THE CC5-STYLE WINDOW" (the user's words verbatim).

## 1 · The job

JustStage's window looks and works like CC5 (the user's 14 screenshots), with MetaHuman Creator's viewport tools;
Blender's own UI hidden but reachable. Built only while waiting for the card, never hurting another session: tests run
headless on the processor; a window screenshot (a GUI Blender for a minute, ~0.5 GB of card) only when the card has
2 GB+ headroom or is free, and the holder is told first.

## 2 · The recs, attacked again before building (what each attack changed)

1. **One Character window; the Modify panel's tabs replace R6's seven workspaces.** Attack: Blender keeps a mode per
   workspace (sculpt, paint) - one window in object mode can't hold sculpting. Kept, with sculpting and clothes
   simulation as their own workspaces when built. Attack: the 3D view's sidebar is narrow for CC5's tree + sliders
   side by side. **Changed:** the Morph tab puts the region tree ABOVE the sliders (a row of region buttons), not
   beside them; the sidebar's width is set wide in the startup layout.
2. **Mouse and keys.** Attack: CC5's Pan X / Zoom Z / Orbit C collide with Blender's X (delete), Z (shading pie), C
   (circle select) - Blender users and Blender's own tools (reachable through "advanced") lose them. **Changed:** not
   now; the camera's Pan / Zoom / Orbit / Home / Frame as toolbar buttons (CC5's camera toolbar), keys later as an
   opt-in "CC5 keys" preset in the template's keymap.
3. **Hide Blender's UI, reachable from Window > Blender (advanced).** Attack: hiding the top bar's menus hides undo
   history, preferences and import/export. **Changed:** our File keeps Blender's import/export submenus and
   Preferences; Edit keeps Undo / Redo / Undo History; only Blender's workspace tabs, editor menus (Add, Object, ...)
   and mode switch go.
4. **The startup layout (Content left, Modify right).** Attack: a layout can only be built with window operators
   (area split) - not in a headless run; a committed binary `startup.blend` is how Blender's own templates do it, but
   is not diffable. **Changed:** a builder script (`tools/make_startup.py`) run once in a GUI Blender writes
   `template/juststage/startup.blend`, committed with it - the script is the source, the file the build.

   Expressions - over what already exists.

3. The top bar: a short, plain set - the user (2026-11-03): "the menus dont have to match exactly just what makes

4. The camera toolbar (Home, Zoom, Pan, Orbit, Frame; quality Medium / High / Epic; light) and MetaHuman's viewport

5. The startup layout: Content (Asset Browser) left, viewport centre, Modify right, Scene Manager (Outliner) - built
   by `tools/make_startup.py`.
6. The splash: New human, recent characters.
